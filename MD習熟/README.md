仕様書が参照する`MD_output_guide.ipynb`は、既存計算の出力を含むローカル教材です。実行環境固有の個人パスが含まれるため、この公開リポジトリには収録していません。利用者の原本は変更せず、ローカルの同じディレクトリに保持しています。

入力準備セットのスクリプトは、参照Notebookがなくてもフォルダ内の構造・設定から利用できます。実分子のGaussian・RESP・力場検証・MDの実行は、入力準備済みの状態とは区別してください。
